## Features

- **Fast & Lightweight** – minimal resource usage.
- **Modern Web Interface** – crafted with HTML & CSS for a clean, responsive dashboard.
- **One‑Line Install** – get up and running in seconds.
- **Cross‑Platform** – works on Linux and Windows (via WSL).
- **Easy Configuration** – all settings at your fingertips.

---

## Installation

Run the following command in your terminal:

```bash
bash <(curl -s https://raw.githubusercontent.com/StriderCraft315/Nvm/refs/heads/main/nvm-v4.sh)
```

The installer handles all dependencies, sets up a **systemctl service**, and launches the panel automatically.

---

## Usage

After installation, the panel runs as a background service. You can manage it with:

```bash
sudo systemctl start nvm
sudo systemctl stop nvm
sudo systemctl status nvm
```

Then open your browser to `http://localhost:5000` (or the IP of your server) and log in with the default credentials (printed during install).
